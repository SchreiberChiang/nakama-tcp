## 复现方式

使用两个新的基线检出，确保父目录没有此项目 skill；两组均保留基线原版文档，复制相同 `fixtures/vehicle-demo/` 到 `evaluation-input/vehicle-demo/`。仅有 skill 组复制本次 `.agents/`。不要把本报告、测试输出或评判标准复制给评测会话。

后续需要抽查时，优先在独立副本上采用宿主支持的受限只读环境，只开放题目所需源码、技能和夹具的读取；限制其他目录和非必要网络访问，禁止受测代理修改文件、启动服务或委派。由外部采集进程将日志写入指定本地目录，不因此开放受测代理的源码写权限。先用最小读取确认权限可用，记录实际允许范围；只读任务提示与独立检出都不能替代操作系统级隔离。

由 `cases.json` 的 `common + "\n\n" + prompt` 生成纯文本，交给新会话。对照保持模型、推理等级、题目、代码基线和权限一致，不继承旧上下文；模型不可用或读取受阻应记环境失败，不默默换模型、不自动升级高权限。需要改变环境时先说明最小必要范围，依照当前授权另行处理，并将新结果与历史运行分开。每次保留 JSONL、stderr、退出码、prompt/HEAD/文件摘要；完整日志留本地。本节只提供后续受限复现方法，本次未执行。

本次可复查的本地采集程序位于 `.local/skill-eval/`：`probe.py` 使用当前CLI生成schema的 initialize/skills/list/model/list；`run_case.py` 从固定题目生成新会话；`collect.py` 对照原始会话注入和成功工具输出中的完整正文；`check_files.py` 检查本地引用与UI字段。它们是本次验证辅助，不是运行时或新增项目管理系统。所有关键采集结果已保存于本目录，可不依赖这些本地脚本阅读。
