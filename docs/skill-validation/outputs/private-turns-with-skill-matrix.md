**模块适配：保密与防连点**

服务端保存牌库、全部手牌、行动顺序和胜负。快照只给本人手牌，其他人只见允许公开的张数、已出牌和状态；结算只给得分及公开信息。**结算阶段的快照与结算结果都要过滤**，公共选项、错误文本和日志也不能夹带秘密。

出牌用一次性 `command`；选牌高亮、动画在本机即时反馈，扣牌和推进回合等待权威确认。当前仍周期发送整份投影，不能当成“仅变化时发送”。

每次 `submit_input` 都生成新序号，且不返回序号，所以连点会产生不同命令。[代码](</<with-skill>/client/core/session.gd:433>) 推荐模块携带“行动编号＋动作ID＋牌实例ID”，在实际消费时检查轮到谁、牌是否仍在手中、动作是否已处理，再一起扣牌和推进回合。按钮锁只是体验辅助。模块回传动作成功或拒绝；底座的 `applied` 只表示消费，32条结果环之外仍可能未知，不能据此自动重出。
