## 尚未验证

- 提取后的模板在微信开发者工具、iPhone/Android、Web 浏览器、公网多人、生产后端、Linux/macOS 上均未运行验证。
- PCK 验收使用桌面 Godot 运行时；没有分发/验收完整 Windows 可执行应用或 Web WASM，平台 export templates 由使用者准备。
- UI 未接入聊天面板；保留的聊天 API/服务端策略没有在新模板重做聊天全流程、长期负载和真实键盘测试。
- 邮箱登录 API 保留，但当前 UI 只提供设备账号；未在本次重新验证邮件账号、找回密码或生产身份方案。
- 最小 fixture 只验证房间生命周期与计数权威，不代表未来任何游戏业务、物理、胜负或反作弊已通过。
- 底座不保证平台 shader/3D 预热、WASM 下载/缓存和启动性能；这里只保证交付默认没有具体游戏资源或后台3D实例。

## 本次修正并复验的问题

首次测试的测试资源遍历曾遇到已释放对象引用，已增加实例有效性检查。窗口测试曾读到写入中的 IPC JSON，改为无错误输出的 JSON.parse 返回码检查。最初仅选主场景的导出漏掉 GDScript 全局类/字体依赖，实际包启动门禁发现后改为导出全部已清理资源并明确排除 tests，再在空目录重验成功。这些失败未计为通过结果；最终摘要只取修正后的完整通过轮次。
